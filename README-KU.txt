پەناگەی دڵ — ڕێنمایی بڵاوکردنەوەی خۆڕایی و ئاگادارکردنەوەی ئیمەیڵ

گرنگ:
- ئەم وەشانە کاتێک وتەیەک نێردرا، بۆ ئیمەیڵی خاوەنی فۆڕمی Formspree ئاگادارکردنەوە دەنێرێت.
- وتەکان بە شێوەی ئۆتۆماتیکی لە پەڕەی گشتی بڵاو ناکرێنەوە؛ تۆ پێش بڵاوکردنەوە پشکنینیان دەکەیت.
- پێویستە هەژمارێکی Formspree دروست بکەیت و ئیمەیڵەکەت پشتڕاست بکەیتەوە.

هەنگاوی ١ — دروستکردنی فۆڕمی ئیمەیڵ
1. بچۆ بۆ https://formspree.io
2. هەژمار دروست بکە بە ئیمەیڵەکەت.
3. فۆڕمێکی نوێ دروست بکە و ئەو ئیمەیڵە پشتڕاست بکەوە کە دەتەوێت ئاگادارکردنەوەکانی بۆ بێت.
4. Formspree endpoint ـێکت پێ دەدات، وەک https://formspree.io/f/abcdwxyz . ئەوە لینکی گشتیی فۆڕمەکەتە، نەک وشەی نهێنی.

هەنگاوی ٢ — پەیوەستکردنی فۆڕمەکە بە کۆد
1. فایلەکەی script.js بکەرەوە.
2. لە سەرەتای فایلەکە بگەڕێ بۆ:
   const QUOTE_SUBMISSION_ENDPOINT = "https://formspree.io/f/REPLACE_WITH_YOUR_FORM_ID";
3. بە endpoint ـی ڕاستەقینەی Formspree بگۆڕە. نموونە:
   const QUOTE_SUBMISSION_ENDPOINT = "https://formspree.io/f/abcdwxyz";
4. فایلەکە پاشەکەوت بکە.

هەنگاوی ٣ — بڵاوکردنەوە بە شێوەی خۆڕایی لە Netlify
1. بچۆ بۆ https://app.netlify.com/drop
2. ئەگەر داوای چوونەژوورەوەی کرد، بە هەژمارێک بچۆ ژوورەوە/هەژمار دروست بکە.
3. فۆڵدەری پڕۆژەکە باربکە کە ئەم فایلانەی تێدایە: index.html, style.css, script.js.
4. Netlify لینکێکی گشتی بۆ وێبسایتەکەت دروست دەکات.
5. لینکەکە بکەرەوە و فۆڕمی وتەی نوێ تاقی بکەرەوە.

هەنگاوی ٤ — تاقیکردنەوەی ئاگادارکردنەوە
1. وتەیەکی تاقیکردنەوە لە وێبسایتەکە بنێرە.
2. پۆستی ئیمەیڵ و Junk/Spam بپشکنە.
3. ئەگەر هیچ ئیمەیڵێک نەهات، dashboard ـی Formspree و endpoint ـەکە بپشکنە.

هەنگاوی ٥ — پشکنین و بڵاوکردنەوە
- کاتێک ئیمەیڵی وتەی نوێت هات، وتەکە بخوێنەوە.
- ئەگەر پەسەندت کرد، دەقی وتەکە وەک دانەیەکی نوێ لە defaultQuotes ـی script.js زیاد بکە و دووبارە پڕۆژەکە لە Netlify بڵاو بکەرەوە.
- ئەم وەشانە هێشتا پنێڵی بەڕێوەبەر و بنکەدراوەی هاوبەشی ئۆتۆماتیکی نییە؛ ئەوە دەتوانرێت لە قۆناغی دواتردا زیاد بکرێت.

تێبینیی پاراستن:
- هیچ وشەی نهێنی، API key، یان زانیاریی بانکی لە script.js دانەنێ.
- تەنها endpoint ـی فۆڕمەکە بەکاربهێنە.
- بەشی خۆڕایی و سنووری ناردن لە خزمەتگوزارییەکاندا دەکرێت بگۆڕێت؛ پێش بڵاوکردنەوە مەرجەکانیان بپشکنە.
